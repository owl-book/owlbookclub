# 홈 화면 UI 개선 맥락

## 서비스 핵심 흐름
사용자는 날짜별로 독서모임을 비교하고, 마음에 드는 모임의 원래 신청 페이지로 이동한다.
모든 개선은 이 흐름을 더 빠르고 헛걸음 없게 만드는 데 있다.

## 디자인 시스템 v2.0 규칙 (절대 어기지 말 것)
- 그림자(shadow) 없음. 면 구분은 1px 보더로만
- 모서리 곡률은 모두 4px. 예외는 pill 뱃지(99px)뿐
- 앰버(#D9A441)는 한 화면에 딱 한 번만
- 주색은 잉크 블루, 배경은 흰색, 브랜드 띠는 다크 네이비
- 제목 서체는 Cafe24 아네모네(헤드라인에만, 현행 유지), 본문은 Pretendard 400/500/600만
- 사용자에게 보이는 숫자는 .fig 클래스(고정폭 숫자)
- Tailwind의 임의값(예: rounded-[10px], shadow-*)을 새로 만들지 말고 설정된 토큰만 쓸 것
- 색 대비는 WCAG 2.1 AA 이상 유지

## 개선 우선순위
P0: 텍스트 표기 버그, 폰트 로딩 확인, 디자인 토큰 일관성 점검
P1: 첫 화면 카드 노출, 캘린더 선택 상태, 마감 모임 처리, 뱃지 2단계 체계
P2: 검색창 일체화, '한 달 달력 보기' 버튼, 칩·필터 통일, 날짜 헤더 간격, 하트 정렬
보류(하지 말 것): 그림자, pill 검색창, 글래스모피즘, 8~12px 곡률, 실시간 검색, GNB 메뉴 추가

### 2단계 P0 수정 (2026-10-26)
**바뀐 것**
- 표기 한 곳에서 만들기: `src/lib/format.ts` 신설(`count` 숫자+단위 붙임, `joinDot`·`joinDotText` ' · ' 구분, `dateRange` ' ~ ', `hashTags` '#태그 #태그'). 모임 카드(책방 · 지역, 묶음 기간 '2회', 태그), 날짜 제목('내일 · 10월 27일 (화)', '1개'), 요약줄, 필터 버튼('모임 N개 보기'), 뱃지('N/M회', 'N회 묶음')에 적용. 달력 제목의 '–'는 '~'로 통일.
- 카드 태그: 장르 굵게 표시를 없애고 모두 400 굵기, `#문학 #글쓰기` 형태(상세 화면 태그 상자는 그대로).
- `.fig`(고정폭 숫자) 클래스를 `globals.css`에 정의하고 달력 날짜, 날짜 제목 개수, 모임 시각, 회차 뱃지에 적용.
- 폰트: 아네모네 유지. Pretendard·아네모네 파일에 preconnect/preload 추가, 제목 토큰 t1·t2 굵기 700→600, `font-bold`→`font-semibold`.
- 토큰: 책 표지 그림자·메뉴 `shadow-sm` 제거, 메뉴 왼쪽 막대 4px→1px, `text-white`·`bg-white`·`border-white`→`page` 토큰(로그인 화면 브랜드 색·관리자 화면 제외), 달력 날짜 글자 15px→`text-b2`(14px).
- (요청으로 레이아웃 변경 1건) '신청 마감'·'지난 모임' 뱃지를 모임명 위 줄에서 모임명 끝 바로 오른쪽으로 옮김. '진행 중 3/4회' 뱃지는 시각 옆 그대로.

**내가 내린 결정**: 제목 글꼴 아네모네 유지(Black Han Sans는 미리보기만 보고 채택 안 함), 태그는 `#` 표기, 달력 날짜 14px.

**남은 문제(다음 단계)**: 홈 밖 화면에 남은 그림자(푸시 알림 창·토스트·전시 포스터·알림 스위치), 슬라이더 `clamp()`·표지 `h-[108px] w-[72px]` 등 임의값, 달력 이전·다음 달 `opacity-50` 대비, 카드 첫 화면 노출(P1). 빌드(`npm run build`)는 통과.
- (추가 요청 2026-10-26) '진행 중 3/4회'·'N/M회' 뱃지도 모임명 끝 오른쪽으로 옮김. 순서는 회차 뱃지 → 신청 마감 → 지난 모임. 뱃지 묶음이 제목 옆 한 줄에 안 들어가면 묶음 통째로 다음 줄로 내려가고 제목은 나뉘지 않음(10/26 수정).

### 홈 클릭 측정 준비 (2026-10-26)
**결정**: 구글 애널리틱스(GA4)를 주력으로 쓴다. 이미 있는 자체 기록(신청 클릭·검색·필터·찜·계획, Supabase `events` 표)은 그대로 두고 확장하지 않는다. 신청 클릭은 서버 기록이 안전망이다. (이유: 숫자를 보는 사람이 개발자가 아니라서 기간 비교가 기본인 GA가 맞고, 광고 차단으로 조금 빠져도 전후 비교엔 영향이 작다)
**측정 시작일**: 미정. 코드는 준비됐지만 GA 측정 ID가 아직 연결되지 않았다. **측정 ID를 Vercel에 넣고 배포한 날**을 시작일로 적는다 → 시작일: ____년 __월 __일
**화면 모양**: 바뀐 것 없음(클릭할 때 이벤트만 보냄). 개인정보처리방침에는 구글 애널리틱스·국외 이전 문구가 이미 있음(10/17, 10/23 개정).
